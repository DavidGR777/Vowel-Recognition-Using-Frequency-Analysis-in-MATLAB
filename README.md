# 🎧 Frequency-Based Vowel Recognition in MATLAB

## Description
This repository contains the development of a MATLAB-based project focused on **vowel recognition using frequency analysis**. The system processes audio recordings to extract relevant features in both time and frequency domains, enabling the characterization of vowel sounds.

## Background
Speech signals contain distinctive frequency patterns that allow the identification of phonemes such as vowels. By analyzing these signals in the frequency domain, it is possible to extract meaningful features like energy distribution and spectral components.  

This project applies signal processing techniques to study and differentiate vowels, providing a practical approach to fundamental concepts in signals and systems.

## Objective
The main objective of this project is to develop a system capable of analyzing and characterizing vowel sounds using MATLAB. This includes:

- Recording and processing audio signals  
- Extracting time and frequency domain features  
- Computing signal energy and spectral distribution  
- Visualizing and comparing multiple recordings  

## Features
This repository includes:

- Audio recording system (3 samples per vowel)  
- Time-domain signal visualization  
- Frequency-domain analysis using FFT  
- Energy computation and analysis  
- Energy distribution in the 200–1200 Hz range  
- Automatic saving of `.wav` audio files

## Usage
To run the project:

1. Open MATLAB  
2. Create the following folders:
   - `carpeta_A`
   - `carpeta_I`
   - `carpeta_O`
3. Open the corresponding script (`vowel_A.m`, `vowel_I.m`, or `vowel_O.m`)  
4. Run the script  
5. Press **"s"** to start recording and pronounce the vowel  

The system will automatically process and display the results.
